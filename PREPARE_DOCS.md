# Подготовка документов для участия — план подготовки

Читается после `PARTICIPATION.md`, если пользователь подтвердил, что начинаем готовить документы. Используй уже собранные данные: Блоки 1–7 тендера (извлечены по `CLAUDE.md`), чек-лист требований к составу заявки и к участнику (из `PARTICIPATION.md`), реквизиты компании из `COMPANY.md`, реестр уставных документов из `CORPORATE_DOCS.md`. Папку и файлы заново не запрашивать.

## Уставные документы (копирование готовых файлов)

Если пункт чек-листа «Требования к составу заявки» совпадает с типом документа из реестра `CORPORATE_DOCS.md` (устав, выписка ЕГРЮЛ, договор аренды офиса и т.п.):

- Если в реестре указан конкретный файл — скопируй его из `C:\Users\user\Documents\Claude\Projects\TenderDataExtractor\CorporateDocs\` в `<папка тендера>\Заявка\` (создай папку `Заявка`, если её ещё нет). В плане подготовки для этого пункта указывай статус «Есть готовый файл — скопирован» вместо «заполнить».
- Если в реестре напротив типа стоит `‹добавить›` — не выдумывай источник, отметь пункт в разделе «Недостающие данные» и спроси у пользователя, где взять документ.

## Задача

Составить и вывести в чат пошаговый план подготовки заявки. **На этом шаге ничего не заполнять и не создавать файлы автоматически** — только показать, что и в каком порядке нужно сделать.

## Что включить в план

1. **Список форм/документов для заполнения** — на основе чек-листа «Требования к составу заявки» (из `PARTICIPATION.md`) и фактически найденных в папке шаблонов (Форма 1, Форма 1.1, Форма 2, Форма 4, Форма 5, Форма 8, анкета и т.п.). По каждой форме указать: название файла-шаблона, что нужно в неё вписать, есть ли данные для заполнения (из `COMPANY.md` / документации тендера) или нужно уточнить у пользователя.
2. **Недостающие данные** — если для заполнения какой-либо формы нужны сведения, которых нет ни в `COMPANY.md`, ни в документации тендера (скан паспорта директора, доверенность, независимая гарантия, допуск СРО и т.п.) — явно перечислить, что нужно получить от пользователя.
3. **Порядок действий и сроки** — последовательность подготовки с привязкой к датам из Блока 4 (дата окончания подачи заявок и др.), чтобы было понятно, к какому сроку что нужно успеть.
4. **Следующий шаг** — в конце плана спросить пользователя, готов ли он приступить к заполнению, и с какой формы начать.

Затем в чате: «Готовы начать заполнение? Скажите, с какой формы начать.»

## Заполнение конкретной формы (по запросу пользователя)

Заполнять форму нужно только после явного запроса пользователя на конкретную форму — не запускать автозаполнение всех форм разом без указания.

Когда пользователь называет форму:

1. Определи тип файла-шаблона (`.docx` / `.xlsx`) и используй соответствующий скилл (`docx` / `xlsx`).
2. Заполни данными из `COMPANY.md` (реквизиты организации) и данными тендера (Блоки 1–7).
3. Если для заполнения не хватает данных — спроси пользователя точечно, только по недостающему полю.
4. Сохрани заполненный файл в папку `AIExtract` соответствующего тендера, рядом с XML/CSV — по аналогии с уже сохранёнными файлами (например `Приложение_2_Анкета_претендента_заполнено.docx`). Имя файла: `<исходное_имя>_заполнено.docx` / `.xlsx`.
5. Передай файл пользователю через `present_files`.

## Ограничения

- На этапе плана — не создавать и не заполнять файлы, только показать план.
- Не выдумывать данные, которых нет ни в тендере, ни в `COMPANY.md`.
- Каждое поле формы заполняется только фактическими данными — если данных нет, оставить пометку `[уточнить у пользователя]`, а не придумывать значение.

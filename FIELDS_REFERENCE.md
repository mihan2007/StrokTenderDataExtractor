# Где искать и редактировать поля — быстрый указатель

Навигационный индекс по всем местам в проекте, где определяются и хранятся поля тендера: что извлекается, как называется колонка в XML/CSV/NocoDB, где лежит форматирование значений. Не дублирует инструкции CLAUDE.md — только даёт точные адреса (файл + переменная/строка), чтобы быстро найти нужное место для правки.

Номера строк актуальны на 2026-09-08 и будут расходиться по мере правок — если строка не совпадает, ищите по имени переменной/функции (они не переименовываются просто так).

## Как поле проходит через систему

Одно извлекаемое поле имеет одно "плоское" имя (`flat_name`, например `address`) и до четырёх мест, где оно "живёт":

1. **CLAUDE.md** — Блок N: что и как извлекать из документов тендера (текст инструкции для Клода).
2. **tools/save_tender.py** — `FIELD_MAP` (flat_name → XML-тег) и `CSV_COLUMNS` (порядок колонок в `all_tenders.csv`).
3. **tools/nocodb_client.py** — свой отдельный `FIELD_MAP` (flat_name → русское название колонки в NocoDB).
4. **Сама NocoDB** — настройки колонки (тип, rich text/Markdown и т.п.) — не в коде, только через Meta API или руками в UI.

Изменение имени или состава поля обычно требует правки нескольких мест из списка — этот файл существует, чтобы ничего не забыть.

## Сама NocoDB (не в коде проекта)

Часть настроек видна только через Meta API (`GET /meta/tables/{TABLE_ID}` — `TABLE_ID` см. в nocodb_client.py) или в UI NocoDB, в файлах проекта их нет:

- `meta.richMode` — включает Markdown-форматирование (жирный текст, списки) для LongText-колонки. Сейчас включено на «Наименование предмета закупки», «Файл-источник», «Адрес заказчика».
- Тип колонки (Decimal/LongText/URL/SingleLineText/...), `meta.precision`, `meta.separator` — история решений и найденные особенности API см. в памяти проекта: `price_format_comma_separator.md`, `address_bold_formatting.md`, `nocodb_integration.md`.

## Типичные правки — что где менять

| Задача | Что менять |
|---|---|
| Добавить новое извлекаемое поле | CLAUDE.md (нужный Блок + шаблон XML + шаблон CSV) → `BLOCKS`/`FIELD_MAP`/`CSV_COLUMNS` в save_tender.py → `FIELD_MAP` в nocodb_client.py → колонка в NocoDB (вручную или через `AUTO_CREATE_COLUMNS`) |
| Переименовать колонку в NocoDB, не трогая извлечение | только `FIELD_MAP` в nocodb_client.py + переименовать саму колонку в NocoDB |
| Изменить форматирование значения для NocoDB (как с адресом/ценой) | новая/изменённая функция рядом с `to_comma_decimal`/`bold_address_except_index`, вызов внутри `upsert()`; если нужен Markdown — не забыть включить `meta.richMode` на колонке через Meta API |
| Изменить состав/тип колонок «Спецификации» | `SPEC_COLUMNS`/`NUMERIC_SPEC_COLUMNS` в nocodb_client.py |

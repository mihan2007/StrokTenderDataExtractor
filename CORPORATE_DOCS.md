# Уставные документы компании — реестр файлов

Папка с самими файлами: `CorporateDocs\` (внутри папки проекта).

Этот файл — явное соответствие «тип документа → конкретный файл», чтобы при подготовке заявки (`PREPARE_DOCS.md`) не угадывать по названию, а брать точный путь. Обновляйте таблицу вручную при добавлении/замене файлов в `CorporateDocs\`.

**Реквизиты юр. лица и данные по конкретным файлам временно очищены — будут добавлены позже вместе с `COMPANY.md`.**

Добавляйте новые строки по мере появления новых типов документов, которые запрашивают заказчики.

## Как это используется

В `PREPARE_DOCS.md`, при формировании плана подготовки заявки, для каждого пункта чек-листа «Требования к составу заявки» (из `PARTICIPATION.md`), если он совпадает с типом документа из этого реестра — файл берётся по точному пути из колонки «Файл» и копируется в `<папка тендера>\Заявка\`, а не разыскивается заново.

Если в реестре напротив нужного типа стоит `‹добавить›` (файл ещё не занесён) — это явный сигнал спросить пользователя, где взять документ, а не пытаться угадать.

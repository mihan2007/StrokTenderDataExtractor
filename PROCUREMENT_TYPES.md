# Справочник видов закупочных процедур

## Когда открывать этот файл

Только если в Документации/Извещении НЕТ прямого названия процедуры («конкурс», «аукцион», «запрос котировок» и т.п. явно не встречается). Если название есть — брать его **дословно из документа**, в этот файл не заглядывать (правило Блока 1 «Тип процедуры» не меняется: копировать точную формулировку заказчика, включая нестандартные названия вроде «Состязательный отбор», «Котировочная сессия» — см. раздел «Нестандартные названия» ниже).

Если названия нет — определить тип по признакам ниже и записать **одно из фиксированных значений** (список в самом низу файла), никогда не «Не указано в документах» (сама процедура идёт всегда, даже если названа общими словами — «конкурентная закупка», «торги» и т.п.).

## Быстрая классификация по признакам

| Наблюдаемый признак в документации | → Тип процедуры |
|---|---|
| Единственный критерий оценки — цена; участники **пошагово снижают цену** после подачи заявок (есть «шаг аукциона», торги в реальном времени на ЭТП) | Электронный аукцион |
| Единственный критерий — цена, но снижение идёт **не в реальном времени/шагами торгов**, а через переторжку/понижающие предложения без формального «шага аукциона»; заказчик не обязан заключать договор с победителем | Редукцион |
| Оценка по цене **и** неценовым критериям (опыт, квалификация, сроки, тех. предложение) по заранее объявленной методике/весам критериев; заявки после подачи не меняются | Конкурс |
| Оценка только на соответствие требованиям + наименьшая цена; **короткие сроки** размещения (минимум ~5 рабочих дней); нет вскрытия/переторжки как отдельного этапа | Запрос котировок |
| Оценка по цене и неценовым критериям, но участникам разрешено **дорабатывать/уточнять** предложение после первичной подачи (без прямых переговоров) | Запрос предложений (запрос коммерческих предложений, КП) |
| Заказчик **напрямую обсуждает условия** (цену, сроки, тех. детали) с одним или несколькими участниками до подписания договора, есть этап переговоров | Конкурентные переговоры |
| Договор заключается напрямую с одним конкретным поставщиком без сопоставления заявок (обоснование — единственный производитель, срочность, малая сумма и т.п.) | Закупка у единственного поставщика |
| Явно указано, что участниками могут быть **только субъекты МСП** (иногда + самозанятые на НПД), при этом остальные признаки (аукцион/конкурс/котировки) не проговорены отдельно — заказчик использует собственное упрощённое название процедуры | см. «Нестандартные названия» — обычно это авторское название конкурентной закупки для МСП (тип по факту ближе всего к запросу котировок/предложений — судить по критериям оценки выше) |

Если по тексту одновременно видно несколько признаков — приоритет: сначала проверить наличие пошагового снижения цены на ЭТП (→ аукцион/редукцион), затем — есть ли неценовые критерии оценки (→ конкурс/запрос предложений), и только в последнюю очередь — короткие сроки без вскрытия (→ запрос котировок).

## Определения (223-ФЗ — основной закон для этого проекта)

**Конкурс** — вид торгов, при котором побеждает участник, заявка которого наиболее полно соответствует требованиям заказчика по совокупности заранее установленных критериев (не только цена). Заявки не могут дорабатываться после подачи.

**Электронный аукцион** — вид торгов, при котором единственный критерий — цена, участники состязаются, пошагово снижая цену на электронной площадке в реальном времени (аукционный шаг обычно 0,5–5% НМЦ); побеждает предложивший наименьшую цену.

**Редукцион** — конкурентный способ закупки с понижением цены, близкий к аукциону, но НЕ регулируется ст. 447-449 ГК РФ (регулируется только Положением о закупке заказчика), заказчик не обязан заключать договор с победителем. Формально «наследник» исторического различия аукцион (на повышение) / редукцион (на понижение) — на практике сейчас оба идут на понижение и почти не различимы, кроме юридического режима.

**Запрос котировок** — упрощённая быстрая процедура: участники подают заявки с ценой, побеждает участник, соответствующий требованиям и предложивший наименьшую цену. Минимальный срок размещения — обычно от 5 рабочих дней. Без отдельного этапа торгов/переторжки.

**Запрос предложений** — участники подают заявки, оцениваемые по цене и неценовым критериям (условия исполнения, квалификация и т.п.); в отличие от конкурса, участникам может быть предоставлена возможность уточнить/улучшить предложение в ходе процедуры.

**Конкурентные переговоры** — заказчик открыто или конфиденциально обсуждает существенные условия будущего договора (цену, сроки, форму оплаты, техническую часть) с участниками до подписания договора; двухэтапно: переговоры → выбор итогового предложения. Разрешено как отдельный «иной способ» в Положении о закупке (в отличие от 44-ФЗ, где переговоры в конкурентных закупках по общему правилу запрещены).

**Закупка у единственного поставщика/подрядчика** — неконкурентный способ, договор заключается напрямую, без сопоставления нескольких заявок; основания — в Положении о закупке заказчика (малая сумма, единственный производитель, безотлагательность и т.п.).

**Переторжка** — НЕ отдельная процедура, а дополнительный факультативный этап внутри конкурса/запроса котировок/запроса предложений, на котором участникам предлагают снизить цену/улучшить условия после вскрытия заявок. Указывается отдельно в поле «Уторговывание / переторжка / редукцион» Блока 1, а не в «Тип процедуры».

## Определения (44-ФЗ — на случай если заказчик прямо ссылается на этот закон)

Для 44-ФЗ действует закрытый перечень способов (в отличие от 223-ФЗ, где заказчик может придумывать «иные способы» в своём Положении):
- **Открытый конкурс** — способ по умолчанию, когда нет прямых указаний на другое; участвуют все желающие.
- **Конкурс с ограниченным участием** — для сложной специфической продукции/ограниченного круга поставщиков (в т.ч. объекты культурного наследия).
- **Двухэтапный конкурс** — 1-й этап: техническое предложение без цены; 2-й этап: цена. Для архитектуры, стройки, НИР, искусства.
- **Закрытый конкурс** — узкому кругу поставщиков (гостайна, драгметаллы, музейные ценности).
- **Электронный аукцион** — определение как в 223-ФЗ выше, обязательно в электронной форме.
- **Запрос котировок** — как в 223-ФЗ выше.
- **Запрос предложений** — как в 223-ФЗ выше.
- **Закупка у единственного поставщика** — лимиты: как правило, до 600 тыс. руб. за контракт (независимо проверять лимит в момент чтения — регулярно меняется Правительством), и/или иные основания ст. 93 44-ФЗ.

## Нестандартные («авторские») названия процедур — как определять содержание

223-ФЗ разрешает заказчику вводить собственные, «иные способы закупки» в своём Положении о закупке — при условии соблюдения общих требований закона (эл. форма, извещение, сроки и т.п.). Крупные заказчики часто дают таким процедурам свои названия. Список уже встреченных в этом проекте (пополнять по мере обработки новых тендеров):

| Авторское название | Кто использует (наблюдалось) | Что это по сути |
|---|---|---|
| «Состязательный отбор» (обычно + «участниками которого могут быть только субъекты МСП») | ПАО «РусГидро» (и, вероятно, другие компании группы РусГидро) | Упрощённая конкурентная процедура специально для закупок среди субъектов МСП по Постановлению Правительства РФ № 1352 от 11.12.2014. НЕ требует обязательно быть одним из 4 «классических» способов — заказчик вправе описать собственную процедуру в Положении при соблюдении базовых требований 1352-го постановления (электронная форма, сроки, доступность для МСП). По критериям оценки — обычно ближе всего к запросу котировок/предложений (см. таблицу признаков выше — проверять индивидуально по документации). |
| «Котировочная сессия» | наблюдалось у отдельных заказчиков (не РусГидро) | По сути аналог запроса котировок — короткая процедура с одним основным критерием (цена), проводится сессией на ЭТП. Если заказчик не 223-ФЗ, а прямо ссылается на портал поставщиков/44-ФЗ малый объём — там это официальный термин для закупок малого объёма через ЕИС/портал поставщиков (не то же самое, что обычный запрос котировок по ст. 24.1 44-ФЗ). Уточнять по контексту, какой закон/портал упоминается. |
| «БРИФ» (Best Response in Fixed Time) | Госкорпорация «Росатом» и организации атомной отрасли (проводится на портале zakupki.rosatom.ru / ЭТП «Фабрикант», «Атомторг») | Многокритериальная закупочная процедура по Единому отраслевому стандарту закупок (ЕОСЗ) Росатома: оценка не только по цене, но и по совокупности критериев (опыт, качество, сроки, гарантии), с финальным этапом **очной переторжки** в режиме реального времени, где идёт основная борьба по цене. Есть и неконкурентный вариант «закупка БРИФ» (аналог закупки у единственного поставщика через тот же функционал) — отличать по документации (конкурс нескольких участников vs. прямое заключение с одним). См. также правило ниже про составное значение `БРИФ-Переторжка`. |

**Правило записи в «Тип процедуры»:** если у заказчика есть собственное название — писать его дословно, как в примере из Блока 1 текущего правила (`или иное — указать точное название из документа`). Этот файл используется только чтобы ПОНЯТЬ суть процедуры (для смежных полей — например, для «Уторговывание/переторжка/редукцион», для оценки, ожидать ли отдельный этап аукциона/переторжки), а не чтобы подменить авторское название одним из «классических».

**Отдельное правило для БРИФ (поле «Уторговывание / переторжка / редукцион», Блок 1):** если тип процедуры — БРИФ и по документации предусмотрен этап переторжки (обычно предусмотрен — это стандартный финальный этап БРИФ) — записывать в это поле составное значение `БРИФ-Переторжка` (а не просто `Переторжка`), чтобы было видно, что это специфичный для БРИФ формат переторжки. Если переторжка в конкретной закупке БРИФ не предусмотрена — обычные правила поля (`Не предусмотрено` и т.п.).

- `Редукцион`
- `Конкурс`

- `Запрос предложений (запрос коммерческих предложений, КП)`
